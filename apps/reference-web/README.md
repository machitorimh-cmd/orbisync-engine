# 星あかりの島 — OrbiSync 3Dデモ

日本語で遊べる、小さな3D探索ゲームです。浮島で星のかけらを５つ集め、中央の灯台をともすとクリア。時間制限や落下によるゲームオーバーはありません。

## 起動

一人用の起動、オンライン接続の前提、２窓のログイン、終了方法は[デモの起動方法](RUNNING.md)を参照してください。

Node.js 22以上が必要です。リポジトリのルートで実行します。

```powershell
npm ci --prefix apps/reference-web
npm run dev --prefix apps/reference-web
```

ブラウザで http://127.0.0.1:5173 を開き、「冒険をはじめる」を選択します。サーバーやアカウントなしで一人用を遊べます。3D形状はコードで生成するため、外部画像・モデル・フォントのダウンロードはありません。

起動・ビルド・型検査の前に、このアプリにインストールしたBufでSDKのTypeScriptプロトコルを自動生成します。Rust用ジェネレーターやグローバルインストールは不要です。生成物はリポジトリの既存方針どおりgit管理外です。

## 操作

| 操作         | キー・ボタン                           |
| ------------ | -------------------------------------- |
| 移動         | WASD / 矢印 / タッチ方向ボタン         |
| 走る         | Shiftを押しながら移動                  |
| ジャンプ     | Space / ジャンプボタン                 |
| かけらを拾う | 近づくと自動収集                       |
| 灯台をともす | ５つ集めて灯台に近づき、E / 点灯ボタン |
| 再プレイ     | やり直す / クリア画面の「もう一度」    |

足元の矢印と目標までの距離が、次のかけら・灯台を案内します。「遊び方」を開いている間とバックグラウンドではゲーム進行を停止します。音は初期状態でオフです。

## OrbiSyncへの接続

「友だちと同じ島へ」でサーバーURL・ログインID・パスワード・既存のインスタンスIDを入力します。同じルームに参加したクライアントの位置と向きを表示します。収集・灯台の点灯・タイムは各プレイヤーのローカル状態です。協力プレイの共有スコアやサーバーによるゲーム進行判定は実装していません。

バックエンドの起動とユーザー作成は[ルートREADME](../../README.md)、World/Instance作成は[公開API](../../openapi/orbisync-v1.yaml)を参照してください。インスタンスは参加できる状態で、アカウントには参加・Entity生成・自分のEntity更新権限が必要です。サーバーのCORS許可オリジンには `http://127.0.0.1:5173` を設定してください。Viteが別ポートで起動した場合、そのオリジンも合わせてください。

既存SDKによるREST認証 → one-time ticket → protobuf WebSocket → 入室 → Snapshot/StateDelta受信 → TransformInput送信を使用します。位置送信は最大10Hzで、サーバーが返したリビジョンを次の更新に使います。８秒間応答がない場合は通信終了を表示し、一人用の探索を続けます。サーバーの移動制限によって拒否された場合も日本語で案内します。再接続する場合はページを再読み込みしてください。

オンラインはこのデモ専用の空のルームを使ってください。受信したTransform付きEntityを他プレイヤーとして表示します。退出した相手は更新が12秒途絶えると非表示になります。サーバー側Entityの永続化・清掃はサーバー運用に従います。

## 検証

```powershell
npm run build --prefix apps/reference-web
npm exec --prefix apps/reference-web -- playwright install chromium
npm test --prefix apps/reference-web
```

Playwrightでゲームルール、フレームレート間の移動距離、キーボードからの収集、ヘルプ中の停止、リセット、スマートフォン表示、接続失敗を検証します。ブラウザテストにはソフトウェアWebGLを使用します。実サーバーとの複数人接続は、起動済みバックエンドを用意して別々のアカウント・ブラウザで同じインスタンスに参加して確認してください。

## 構成

SDKの初期同期完了を待って送信し、静止中も個別Entityのrevision進行で応答を確認します。このコピーの作成時に実サーバー接続や負荷試験は再実行していません。利用する環境で接続動作を確認してください。

- `src/game.ts`: 移動・衝突・収集・クリア判定
- `src/scene.ts`: Three.jsによる島・灯台・アバター・描画
- `src/main.ts`: 日本語UI・入力・音・ゲームループ
- `src/online.ts`: 既存OrbiSync SDKとの接続
- `src/style.css`: デスクトップ・モバイル画面

Three.jsの描画設定は[公式ドキュメント](https://threejs.org/docs/pages/WebGLRenderer.html)を参照しています。

The separate REST and realtime reference console is in `../reference-console-web/`.
